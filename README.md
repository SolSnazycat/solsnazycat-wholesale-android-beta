# SolSnazycat Wholesale Android Beta

Try the Android app for [SolSnazycat Wholesale](https://wholesale.solsnazycat.ca/). The beta supports browsing the store in the app or opening it in your browser.

## Download

[Download the v0.1.0 beta APK](https://github.com/SolSnazycat/solsnazycat-wholesale-android-beta/releases/download/v0.1.0-beta/SolSnazycat-Wholesale-Beta-v0.1.0.apk) · [Read the release notes](https://github.com/SolSnazycat/solsnazycat-wholesale-android-beta/releases/tag/v0.1.0-beta)

Anyone can download the APK. A GitHub account is required to file an issue.

## Report a bug or suggest an improvement

This is an early beta, so you may encounter bugs. [Open an issue](https://github.com/SolSnazycat/solsnazycat-wholesale-android-beta/issues/new/choose) and include your phone model, Android version, app version, whether you were using embedded or browser mode, and the steps to reproduce the issue. Keep account, payment, and order details out of issue reports.
